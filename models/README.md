# FoodBridge AI - Trained Models Directory

This directory stores serialized Machine Learning model artifacts (`.joblib` or `.pkl` files).

### Planned Models:
1. `demand_forecast_model.joblib`: Supervised regression model trained on historical meal demand.
2. `recipient_matching_weights.joblib`: Parameter weights for multi-criteria ranking.

*Note: In Milestone 1, this directory is initialized and ready for model persistence in Milestone 2.*
